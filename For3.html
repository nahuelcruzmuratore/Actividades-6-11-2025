El sistema permite al usuario registrar las ventas de cinco empleados y determina cuántos de ellos cumplen con la meta mensual establecida. Primero, el usuario ingresa el valor de la meta de ventas que se debe alcanzar. Luego, el sistema solicita las ventas de cada empleado de manera individual. Por cada empleado, verifica si sus ventas son mayores o iguales a la meta; si es así, incrementa un contador que lleva la cantidad de empleados que cumplieron la meta. Al finalizar, el sistema muestra un mensaje indicando cuántos empleados alcanzaron la meta.
