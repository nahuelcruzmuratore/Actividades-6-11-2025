Escribí un programa en JavaScript que permita controlar los gastos a partir de un presupuesto inicial. El programa debe: Pedir al usuario que ingrese el presupuesto disponible. Solicitar el valor de cada compra e ir descontando su costo del presupuesto. Mostrar después de cada compra cuánto dinero restante queda disponible. Finalizar el proceso cuando el usuario ingrese 0 como valor de compra. Al finalizar, mostrar el total gastado con dos decimales.
